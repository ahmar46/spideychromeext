✳ web buddy

Your breaks are your business.

Privacy policy · Version 1.2.1 · 25 November 2026

Web Buddy is a local browser companion that reminds you to drink water, rest your eyes, and stretch. It does not send your data to the developer or to third parties.

What stays on your device

The extension uses Chrome’s local extension storage for reminder intervals, enabled reminder types, pause state, appearance preferences, the hostnames you choose to hide Web Buddy on, reminder deadlines, a pending reminder, and today’s completed-break counts and local date. This data is not synced through Chrome Sync by Web Buddy.

Website access

Web Buddy adds its character and reminder controls to regular HTTP and HTTPS webpages. It uses the current hostname to apply your per-website preference and the page’s visibility state to hide the character in background tabs. When you open the toolbar popup, the activeTab permission lets the popup identify the current website for that control. Web Buddy does not read or collect page text, form inputs, passwords, cookies, search queries, or browsing history. It does not store full webpage URLs or a list of websites you visit. Only hostnames you explicitly disable are saved.

No remote services

All extension code and artwork are included in the installed package. There are no accounts, ads, analytics, tracking pixels, remote fonts, remote code, external AI services, or network requests made by Web Buddy. No local data is sold, shared, or transmitted by the extension.

Controls and retention

You can pause reminders, disable a reminder type, hide the companion on a particular website, and restore hidden websites from the popup. Daily completion totals reset when the local calendar date changes and the extension next processes an event. Preferences remain in local storage until changed or removed. Removing Web Buddy from Chrome removes its extension-local storage; Chrome-managed backups are controlled by your browser and operating system.

Permissions

Storage: save your local preferences and reminder state. Alarms: wake the background worker to process reminders. Active tab: identify the current website when you open the popup. Scripting: add or repair the local companion script in the active page when you explicitly launch a reminder from the toolbar. The declared HTTP and HTTPS content-script matches allow the companion to appear on regular webpages.

Contact

Contact the developer through the support contact on Web Buddy’s Chrome Web Store listing. Before a public listing exists, contact the person who provided this extension package.

Changes

If Web Buddy’s data practices change, this policy and the extension’s store disclosures must be updated before the changed version is published.
